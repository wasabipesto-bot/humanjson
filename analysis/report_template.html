The human.json vouch graph

human.json is a small protocol, launched in March 2026, that lets a personal website state that it's written by a human and vouch for other sites it believes are human-made too. A site adds a <link rel="human-json"> tag pointing to a JSON file that lists the URLs it vouches for, each with a date. Verifiers, such as the browser extensions, follow those vouches outward from sites you already trust, building a web of trust one hop at a time. This page maps that web: every file we can find, who vouches for whom, and how the network changes week to week.

The network

Each dot is a site. Blue sites publish a human.json file; gray sites are vouched for but publish none. Dot size follows how many sites vouch for it. The ring around the edge holds sites that share no vouch with the main network: a file whose targets nobody else vouches for, or a file with no vouches at all. Has trust been withdrawn?

Vouches present in one version of a file and missing from the next, across Wayback Machine captures (then today's crawl) and the git history of files kept on GitHub. The protocol has no revocation, so deleting the vouch is the only way to withdraw it.
